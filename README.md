# Cooler cities 公共空间降温方案比较平台

公开网页发布源：main分支根目录，使用GitHub Pages。

五个固定方案、费用核算、设施故障与服务容量、数据导入导出及参数分享。当前片区待定，费用、容量及需求为测试假设，热环境待接入。示意图不代表兰州真实地图。

仓库包含两个附件的精简替换稿、实施流程、数据格式与CSV采集模板。原始参赛附件和私人联系方式未上传。

当前网页采用离线模型结果展示，浏览器不求解微气候。费用与容量规则在浏览器中执行，不需要服务器或API密钥。上传JSON只影响当前浏览器；公开数据更新需提交data.js。


## 兰州方案决策展示（2026-10-19）

在线：https://yazov7190-svg.github.io/urban-octo-giggle/

新增真实街道地图与目标/预算规则初筛。50个街道、107个公园要素，以及浏览范围内OSM建筑、道路、水体。地图可以选择街道并开关图层；所选街道仅为浏览范围，并非已确定的干预单元。费用、人数、容量继续采用明确标注的演示假设；尚无微气候计算结果。

决策规则：按短期遮阳、长期增绿或铺装更新匹配预设方案；按建设预算筛选，然后按评价期费用从低到高排序。没有预算内匹配方案时不推荐。街道选择不改变费用或热环境参数。可导出含选区、目标、候选方案、费用条件与服务推演的JSON。

地图数据来自团队提供的街道、公园与甘肃OSM数据。仅保留边界、街道名称和所属区等展示字段；七普人口及原评价指标未发布。OSM数据 © OpenStreetMap contributors，ODbL：https://www.openstreetmap.org/copyright 。未核实原始文件更新时间；本图不声称反映最新行政区划和设施现状。地理数据不含遥感影像，影像尚未发布。

快速演示：选张掖路街道→优先短期遮阳→建设预算3万元→候选遮阳→应用方案→设置A停用→开放C并将开放时间提前到13时→导出决策说明。示例14时需求200人、B容量80、C容量60，A停用时缺口由120降至60；这不是实测服务结论。
