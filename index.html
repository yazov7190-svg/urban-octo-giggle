实施流程

先做一个可核查的案例

  1. 确定边界选择一处广场、街段或校园公共空间，提供名称、地图范围和现场照片。
  2. 整理基础数据建筑高度、树冠、铺装、逐时气象、候选设施与容量；每项注明来源。
  3. 计算五组方案现状、增绿、遮阳、材料、增绿＋遮阳。使用同一气象和统计范围。
  4. 填入费用与设施措施数量、单价、运行维护和寿命；服务点容量和运行时段。
  5. 接入并核查导入数据包，核对原始结果、费用手算、故障前后容量与未服务人数。
  6. GitHub 发布版本化保存代码和可公开数据，GitHub Pages提供网址，其他人直接打开。

GPT可以处理表格、转换结果、编写界面和报告；真实现场信息与物理模型结果需要有来源。网页不会调用GPT生成降温量。
